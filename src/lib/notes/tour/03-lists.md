# Lists and todos

- Start a line with `-` for a bullet
- Press Enter to continue the list
  - Tab nests an item under the one above
    - Each level gets its own bullet
  - Shift-Tab moves it back out
- Enter on an empty item ends the list

1. Numbered lists count for you
2. Renumbered as you go
3. And nest as an outline does
   1. Lettered under a number
      1. Then in Roman numerals
   2. Settings → Editor numbers them other ways
4. Type `- ` at the start of an item to make it a bullet, `1. ` on a bullet to number it

## Moving things

Hover a line for a grip on its left, and drag it to move the line, a list item with everything under it, a heading, table, code block or card. ⌥↑ and ⌥↓ (Alt) move lines from the keyboard, and list items with what's under them. A numbered item moved is numbered for where it lands, its list counting on in the new order. Settings → Editor turns the grips and the renumbering off.
